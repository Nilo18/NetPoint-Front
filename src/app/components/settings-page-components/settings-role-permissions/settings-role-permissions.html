Role Permissions

Understanding access levels in NetPoint

Owner

  • Full system access
  • Add/remove users
  • Modify catalog
  • View all reports
  • Manage settings

Admin

  • Modify catalog
  • View reports
  • Manage inventory
  • Custom attributes
  • Cannot add users

Cashier

  • Process sales
  • View products
  • Manage cart
  • Cannot edit catalog
  • No settings access
