## Overview

This repository contains the frontend implementation for NetPoint, providing user interfaces for both admin management and cashier operations.

## Features
- Admin Interface
- Upload and manage product catalog
- Edit product details
- Cashier (POS) Interface
- Scan product barcodes
- Display product information instantly
- Calculate total price in real time
- Frontend Tech Stack

## Frontend Tech Stack
- Framework: Angular
- Language: TypeScript
- Styling: CSS / SCSS

## Architecture
NetPoint is divided into two main roles:

- Admin – manages products and catalog data
- Cashier – handles scanning and checkout process
